# Hospital Management System – Java Project

This is an object-oriented Java project that models a simple Hospital information system.  
It demonstrates strong OOP design and clear structuring of multiple interacting classes.

---

## 🏥 Features
- Patient management
- Doctor management
- Appointment or treatment logic
- Clear entity relationships (Patient ↔ Doctor)

---

## 🧠 OOP Concepts Used
- Classes & objects  
- Encapsulation  
- Inheritance (if present)  
- Composition  
- Method overriding  
- Project structure organization

---

## 📁 Project Structure
- `/src` – Java classes  
- Entity classes (Patient, Doctor, etc.)  
- Utility and logic classes
